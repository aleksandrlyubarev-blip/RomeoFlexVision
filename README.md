# RomeoFlexVision

Public research and demo surface for visual inspection workflows with human
review and evidence logging.

## Public positioning

RomeoFlexVision is the agent-system and submission wrapper. The public
repository is a generic demo and research surface, not a production customer
deployment.

The current names are:

- **RoboQC** - inspection robot hardware.
- **Neuron Vision Display** - visual inspection software.
- **Checker** - manual scanner.
- **RomeoFlexVision** - agent system and legal submission wrapper.

## Data boundary

This repository is intended for public datasets, synthetic examples, and
generic inspection concepts only.

It must not contain employer data, customer data, production photos, internal
work instructions, proprietary layouts, confidential defect records, or
reverse-engineered geometry from a third-party manufacturing site.
