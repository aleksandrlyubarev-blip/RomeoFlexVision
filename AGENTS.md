# RomeoFlexVision Agents

RomeoFlexVision is the agent-system and legal submission wrapper.

Public vocabulary:

- RoboQC - robot hardware.
- Neuron Vision Display - visual inspection software.
- Checker - manual scanner.
- RomeoFlexVision - agent system and legal submission wrapper.

The `rhaef_v2/` and `roboqc_data/` directories contain experimental
implementation code. They are not production customer deployments.
