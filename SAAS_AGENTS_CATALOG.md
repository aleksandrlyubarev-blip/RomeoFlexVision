# Перепись агентов репозитория → что продавать (полный census)

> **Назначение:** goal-режим, проверка ВСЕГО репозитория. Ответ на вопрос «каких агентов я насеял
> по репо (не обязательно QC) и что из них можно продавать — подпиской или за токены». Companion к
> `SAAS_STRATEGY.md`. Версия 2, 2026-06-24 (расширена за пределы QC).
> **Метод:** код-анализ всех агентных систем + ростера `AGENTS.md` + `.claude/skills` + `larmorsight-office`
> + `scripts/`. Зрелость — строго из кода: «реальный LLM/tool-вызов» vs «заглушка/константа/только имя в доке».
> Ветки проверены: агенты есть только в `main`/рабочей ветке, скрытых в истории нет.

---

## 0. Главный вывод

По всему репо — **15+ агент-подобных сущностей в 4 семействах** (QC-пайплайн, не-QC «офис» из 5
сотрудников, видео-реставрация, ростер RHAEF). Но если отделить **исполняемый код от названий в доке**,
картина резкая:

- **Реально исполняется end-to-end (есть продукт):** `checker`, RoboQC-пайплайн, **RFV видео-реставрация**,
  **5 office-агентов** (как локальные Claude Code плагины), видео-утилиты.
- **Частично (каркас есть, ядро — заглушка):** brigada, voice-gateway, cloud-runtime офиса, Romeo/Coder-узлы.
- **Только на бумаге / 3-строчные заглушки:** Vision Master, Andrew Swarm v2, Bassito Video, Flex Executor,
  4 агента brigada (general/major/sergeant/soldier).

**Два не-QC актива, которые меняют разговор:**
1. ⭐ **RFV (видео-реставрация лиц)** — полностью рабочий, продаваемый **standalone сегодня**, **0 блокеров**,
   к QC отношения не имеет. Это самый недооценённый актив в репо.
2. ⭐ **«Офис» из 5 AI-сотрудников** (research / sales / content / finance / devops) — не-QC, **работают
   прямо сейчас как локальные плагины**, продаются как «AI-команда по подписке».

## 2. Два не-QC сюрприза — крупным планом

**⭐ RFV видео-реставрация — продаваемо сегодня, вне QC.**
`scripts/rfv_pipeline/` — это **полноценный production-pipeline** (3 режима: stream/disk/chunked), который
корректно держит то, что ломает большинство инструментов: VFR, HDR10-метаданные, rotation, audio
passthrough, цветовое пространство. Restorer подключается через чистый контракт — вставляешь
GFPGAN/CodeFormer и продаёшь как «Topaz-подобный» сервис реставрации лиц в видео (старые записи,
интервью, архивы). **Блокеров нет** — нужна только модель-веса + обёртка (UI/API). Это самый быстрый
путь к независимой выручке, не завязанный ни на QC, ни на XPRIZE-дедлайн.

**⭐ «Офис» из 5 AI-сотрудников — не-QC команда по подписке.**
Ты собрал research / sales / content / finance / devops агентов на высоком уровне (SKILL.md +
команды + quality-checklist + friction-gates). **Они исполняются прямо сейчас как локальные Claude Code
плагины.** Сильнейшее позиционирование — не 5 отдельных продуктов, а **«наёмная AI-команда»**:
$2–10k/мес против $50k+ за 5 контракторов. Это отдельная вертикаль, целиком вне QC.

## 3. Монетизация: группировка

**Кандидаты на подписку (seat/станция):**
- `checker` — /станция (готов)
- Office-команда — /seat или пакет-команда (работает локально; нужен cloud-runtime для SaaS)
- RFV — тариф /минуты

**Кандидаты на токены/usage:**
- RoboQC — /инспекция (готов архитектурно)
- RFV — /видео (готов)
- brigada — /изображение (после расзаглушки)
- voice-gateway — /минута (после MES-интеграции)

**Общий рубильник токен-биллинга (один на всех):** per-tenant **метеринг + персистентность** поверх
`ModelRouter.cost_tracker`. Сейчас трекер глобальный, in-memory, без `tenant_id`. Как только появится
`tenant_id` в контексте + запись расхода в Atlas — **токенная монетизация включается сразу для RoboQC,
voice-gateway, brigada и облачного офиса**. ~3–5 дней. Самая высоко-рычажная задача портфеля.

**Общий рубильник для офиса:** один **executable cloud-runtime** (GCS→Anthropic/Vertex→ответ) превращает
все 5 office-агентов из локальных плагинов в SaaS разом. ~2–3 недели (ROADMAP пометил офис на архив —
переоценивать, только если это становится отдельной ставкой).

## 4. Рекомендация по приоритету (с учётом дедлайна 1 авг)

1. **Сейчас, без облака → выручка:** `checker` (подписка/станция) **и** RFV (per-видео) — оба реально
   работают и продаются standalone. RFV вообще без блокеров. Два независимых ручья выручки под
   «arms-length revenue» XPRIZE, не дожидаясь SaaS.
2. **2–4 недели → SaaS-вертикаль заявки:** RoboQC до мульти-тенанта (`tenant_id` + реальный `/inspect`
   + метеринг-рубильник). Это «агентная платформа» из стратегии.
3. **Параллельная ставка (если есть ресурс):** office cloud-runtime → «AI-команда по подписке». Крупный
   не-QC рынок, но требует отдельного спринта; решить — это вторая вертикаль или фокус только на QC.
4. **Потом:** brigada (synthetic-data /изображение) после расзаглушки агентов.
5. **Не монетизировать:** telegram-bot (не агент); Vision Master / Andrew Swarm / Bassito Video / Flex
   Executor — это **только имена в `AGENTS.md` без кода**, продавать нечего (либо реализовать с нуля,
   либо убрать из ростера, чтобы не путать заявку).
