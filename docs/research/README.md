# Research radar

Dated "Pulse" notes tracking external visual-AI / anomaly-detection work that is
relevant to the NeutronVision QC / RoboQC stack. Each note maps items onto
concrete repo artifacts and a next-step hook, so the radar stays actionable
rather than a bare link list.

Conventions:

- One file per pulse, named `YYYY-MM-DD-<topic>.md`.
- Supersede prior pulses with a new dated file rather than editing old ones —
  the dates are the audit trail.
- Public sources only. Prototyping seeded from a pulse stays inside the data/IP
  boundary in the root `README.md`.
