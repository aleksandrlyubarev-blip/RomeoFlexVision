# workspace/templates

Заготовки для новых проектов и задач. Канонические шаблоны офиса лежат в
[`../../references/templates/`](../../references/templates/) — например
`project-brief.md` и `performance-review.md`.

## Как начать новый проект
1. Создай папку `workspace/active/<project>/`.
2. Скопируй туда `references/templates/project-brief.md` как `brief.md` и заполни.
3. Складывай рабочие файлы проекта в эту же папку.
4. По завершении перемести папку в `workspace/archive/`.

Содержимое `workspace/active/` и `workspace/archive/` не коммитится (см.
`../../.gitignore`) — это рабочее пространство, а не часть пакета офиса. Положи
сюда свои дополнительные заготовки, если они нужны команде.
